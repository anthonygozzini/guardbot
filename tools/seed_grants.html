Test grants — testnet only

This page asks a TEST wallet to create a tiny approval on a TESTNET, so GuardBot’s revoke signing can be verified without spending anything. Use throwaway wallets (Phantom in Testnet mode · TronLink on Nile). Never a real seed. GuardBot itself never approves — this page lives outside the product and is served only with GUARDBOT_DEV_SEED=1.

Needs a Solana wallet on devnet: Solflare (Firefox/Chrome extension, switch network to Devnet) or the Phantom app (Testnet mode). Creates the USDC-devnet token account if missing and approves 1 unit to a test delegate (the System Program address).
